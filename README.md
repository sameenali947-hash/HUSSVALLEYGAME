# HUSSVALLEYGAME
The Goal: Matches take place in a rectangular arena (such as Haunted Woods or Schoolyard). • Runners: Most players start as Runners. Your goal is to sprint across the map to reach the safe zone or finish line. • Chasers (Husk): One or more players are chosen as the Chaser. If a Chaser catches you, you turn into a Chaser/Husk too.
